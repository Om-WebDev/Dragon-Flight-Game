# 🐉 Dragon Flight

Dragon Flight is a fun, fast-paced browser game inspired by the classic endless flying style. Control a dragon, dodge obstacles, and survive as long as possible to achieve the highest score.


## ✨ Features

- 🐉 Smooth dragon flight mechanics
- 🎯 Endless gameplay
- 🚧 Randomly generated obstacles
- 📈 Score tracking
- ⚡ Responsive controls
- 🔄 Restart game instantly
- 🎨 Clean and lightweight UI
- 💻 Works in modern web browsers

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- HTML5 Canvas API

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/dragon-flight.git
```

### Navigate to the project

```bash
cd dragon-flight
```

### Run the game

Simply open the `index.html` file in your browser.

Or use VS Code Live Server for the best development experience.
